# Webonza — Riding Cities

Premier projet réalisé dans le cadre de la formation **Intégrateur Web d’OpenClassrooms**.

L’objectif était de prendre en main les bases du développement web en complétant la page d’une association de skateboard fictive, **Riding Cities**, à partir d’une base de code existante.

## Mission

Dans le cadre d’une mission confiée par l’agence fictive **Webonza**, le site devait être enrichi avec de nouveaux contenus tout en respectant la mise en page et l’identité visuelle fournies.

Les principales modifications réalisées sont :

- l’ajout d’une section présentant les membres fondateurs de l’association ;
- l’intégration des photographies et des informations de chaque membre ;
- l’ajout de deux boutons permettant de consulter les plannings des cours pour adultes et pour enfants ;
- la mise en forme des nouvelles sections conformément à la maquette ;
- l’utilisation de balises HTML sémantiques et de textes alternatifs pour les images.

## Technologies utilisées

- HTML5
- CSS3
- Flexbox
- Variables CSS
- Google Fonts

## Organisation des branches

- **`main`** : contient le projet de départ fourni par OpenClassrooms.
- **`dev-branch`** : contient les modifications et les ajouts que j’ai réalisés pour répondre à la mission.

Pour consulter ma version du projet :

```bash
git switch dev-branch
```

## Installation et lancement

Ce projet est un site statique et ne nécessite aucune dépendance.

1. Clonez le dépôt :

```bash
git clone <URL_DU_DEPOT>
```

2. Placez-vous dans le dossier du projet :

```bash
cd Webonza
```

3. Sélectionnez la branche contenant la version finalisée :

```bash
git switch dev-branch
```

4. Ouvrez le fichier `index.html` dans votre navigateur.
